## Overview

**PeaZip** — Free archiver with a friendly UI and strong encryption. It runs on **Windows, Linux** and is distributed under the **LGPL-3.0** license.

If you searched for *"peazip download"*, this is the tool you are looking for. Below you will find a feature breakdown, platform-by-platform installation instructions, a quick-start example, and answers to the most common questions.

## Key Features

- Reads 200+ archive formats
- Strong two-factor encryption
- Secure delete and file hashing
- Batch conversion between formats
- Portable version available
- Cross-platform UI

## FAQ

**How many formats does it open?**

Over 200, including 7z, RAR, ZIP, and ISO.

**Does it encrypt archives?**

Yes, with strong encryption and optional keyfiles.

**Is it portable?**

Yes, a portable build is available.
